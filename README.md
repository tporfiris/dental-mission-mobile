## Build Your Smile Mission Platform

A full-stack mobile and web platform built for the Build Your Smile Foundation to digitize dental mission workflows.

The platform enables volunteer dentists to register patients, chart treatments, record notes, and work completely offline in remote locations. An accompanying admin dashboard provides real-time mission analytics, treatment reporting, and donor impact metrics.

Tech Stack: React Native, Firebase (Firestore, Authentication, Cloud Functions, Storage), TypeScript.

Visit the [Build Your Smile Foundation](https://bysdf.org).
